# 📝 Customized To-Do List

A simple and interactive **Python-based To-Do List application** designed to help users organize and manage their daily tasks.

This project was created as a mini Python project to practice programming concepts such as functions, loops, conditional statements, lists, and user input.

---

## ✨ Features

- ➕ Add new tasks
- 📋 View all tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 🔄 Manage daily tasks easily
- 💾 Simple and lightweight
- 🐍 Built completely using Python

---

## 🛠️ Technologies Used

- **Python 3**
- Python Lists
- Functions
- Conditional Statements
- Loops
- User Input
